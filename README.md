# Flowerword

Студия цветочных букв: печатаешь слово, из букв растут лозы, расцветают розы, летают бабочки. Готовый ролик (MP4/WebM, 1920×1080) скачивается кнопкой.

- 10 цветовых тем, длительность 5 / 10 / 15 секунд
- Тонкие или жирные буквы, необязательная рамка
- Один файл `index.html`, без сервера и без зависимостей, шрифт встроен
- Запись видео работает в Chrome, во вкладке на переднем плане

Как запустить: открыть `index.html` в браузере.
